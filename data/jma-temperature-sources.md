# 熊谷・福岡の日別気温の出典

出典：気象庁「過去の気象データ検索」の日ごとの値。気象庁が公表した2024年8月の熊谷（埼玉県）と福岡（福岡県）の観測値を教材作成者が抽出・加工した。気象庁が作成した教材や推奨する分析ではない。

## 原資料と利用条件

- [熊谷，2024年8月の日ごとの値](https://www.data.jma.go.jp/stats/etrn/view/daily_s1.php?prec_no=43&block_no=47626&year=2024&month=8&day=&view=p1)。地点番号47626。
- [福岡，2024年8月の日ごとの値](https://www.data.jma.go.jp/stats/etrn/view/daily_s1.php?prec_no=82&block_no=47807&year=2024&month=8&day=&view=p1)。地点番号47807。
- [気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)。2026-11-17確認時点で，権利表記のない公開コンテンツには公共データ利用規約（第1.0版）が適用される。出典の記載と，編集・加工した場合はその旨の表示が必要。
- [気温の用語](https://www.jma.go.jp/jma/kishou/know/yougo_hp/kion.html)・[日界の説明](https://ds.data.jma.go.jp/obd/stats/data/mdrr/man/nikkai.html)・[値欄の記号の説明](https://www.data.jma.go.jp/stats/data/mdrr/man/remark.html)。列の定義，日付の区切り，欠測・品質記号を確認する。

原ページを2026-11-17に取得した。公開値が訂正される可能性があるため，教材に収録した版と将来再取得した版の違いを無条件に誤りとは扱わない。

## 加工内容

配布ファイルは `jma-temperature-2024-08.csv`。各地点31日，合計62行・6列。1行は一地点の一日で，期間は2024-08-01〜2024-08-31。原表から気温の平均・最高・最低を選び，地点名・地点番号・年月日を加えた。行順は熊谷の1〜31日，福岡の1〜31日。UTF-8，LF改行，小数第1位の値で保存した。

| 教材の列 | 元の表の項目 | 意味 |
| --- | --- | --- |
| `station` | 表の地点名 | 熊谷または福岡。観測地点を表し，市内の全場所を測った値ではない。 |
| `station_code` | URLの `block_no` | 気象庁の地点番号。文字列として読める識別子。 |
| `date` | 表の年月と日 | 日本の暦日。日ごとの値の日界は24時。 |
| `mean_temp_c` | 気温（℃）の平均 | 1〜24時の毎正時24回の観測値の平均。 |
| `max_temp_c` | 気温（℃）の最高 | 当該一日の最高気温。 |
| `min_temp_c` | 気温（℃）の最低 | 当該一日の最低気温。夜間だけに限定した最低気温とは異なる。 |

選択した186個の気温値に空欄・欠測・品質記号はなかった。補完，除外，丸め直しはしていない。降水量・湿度・風・天気概況の列は配布CSVに含めない。元の表の `--` や `0.0` を同じ欠測に変換したものではない。

再作成には，原ページをUTF-8のHTMLとして保存し，次を実行する。

```text
python scripts/prepare_jma_temperature.py 熊谷の保存HTML 福岡の保存HTML
```

このスクリプトは当該二地点・当該月を対象とする。見出し，31日の並び，選択気温値の形式を確認し，品質記号が現れた場合は処理を止めて資料の再確認を求める。別の表に対して記号を自動で削除する汎用の取得処理ではない。

配布CSVのSHA-256：`d056c7cbab0677559a9004c61434442b4248184a0e2615f7bf9e3506ddba1b18`。

## 照合結果と解釈

標準ライブラリのHTMLParserで抽出した配布CSVを，独立したpandasのHTML表読取結果と照合し，全186気温値が一致した。地点×日付の重複は0，欠測は0，各地点の日付が1〜31日でそろい，全行で最低≦平均≦最高を確認した。

| 2024年8月の比較 | 熊谷（31日） | 福岡（31日） |
| --- | ---: | ---: |
| 日最高気温35℃以上の日数 | 20 | 17 |
| 日最低気温25℃以上の日数 | 24 | 30 |
| 日最高気温の月内平均（℃） | 35.0032 | 34.7581 |
| 日最低気温の月内平均（℃） | 25.6355 | 27.6581 |
| 日平均気温の月内平均（℃） | 29.3548 | 30.4677 |

気象庁は日最高気温35℃以上の日を猛暑日と定義する。一方，熱帯夜は夜間の最低気温25℃以上を指す。本教材では日最低25℃以上をその定義と同一視せず，測定列に即した名前で報告する。公式の気候変動資料には日最低25℃以上を便宜的に熱帯夜とする集計もあるが，その資料固有の定義をこの表の意味へ無条件に持ち込まない。 [気温のFAQ](https://www.jma.go.jp/jma/kishou/know/faq/faq3.html)

この月の記録をすべて用いた記述であり，二地点の長年の気候や別年の8月を無作為抽出した標本とは扱わない。時間的に連続した日を，独立な行として無条件に復元抽出・置換するためのデータでもない。
